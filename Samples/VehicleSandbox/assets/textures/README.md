# Textures Directory (`assets/textures/`)

This directory contains texture maps for vehicles, terrain, road surfaces, and environmental elements.

### Supported Formats:
- **PNG (`.png`)**: Lossless textures with full RGBA alpha support.
- **JPEG (`.jpg`, `.jpeg`)**: High-compression textures for diffuse and background maps.
- **TGA (`.tga`)**: Uncompressed game textures.

### Texture Types:
- `*_albedo.png` / `*_diffuse.png`: Base surface color.
- `*_normal.png`: Tangent-space normal map.
- `*_roughness.png`: Micro-surface roughness map.
- `*_metallic.png`: Metallic reflection map.
