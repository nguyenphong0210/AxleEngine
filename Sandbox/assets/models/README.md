# 3D Models Directory (`assets/models/`)

This directory is designated for all 3D mesh assets used by the project.

### Supported Formats (Phase 9+):
- **glTF / GLB (`.gltf`, `.glb`)**: Recommended format for vehicles, interiors, and scene props with embedded transforms and materials.
- **Wavefront OBJ (`.obj`)**: Universal format for meshes, collision hulls, and track obstacles with `.mtl` material definitions.
