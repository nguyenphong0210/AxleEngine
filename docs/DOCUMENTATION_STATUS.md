# Documentation status

The repository uses one documentation system:

1. Root `ROADMAP.md` is the only execution order and status authority.
2. Each Phase has one `PLAN.md` for progress/review and one `ARCHITECTURE.md`
   for target design and implementation details.
3. Supporting contracts live in `docs/design/` and are linked from Phase
   architecture documents.
4. Verified delivery/review evidence lives in `docs/reviews/`.
5. Superseded plans and historical reports live in `docs/archive/`.

No Phase, OPT, P41, EJ or PLG document outside the root roadmap creates an
independent execution queue. Historical identifiers are retained only for
traceability.
