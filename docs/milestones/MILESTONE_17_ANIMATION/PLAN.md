# Milestone 17 — Skeletal Animation Studio and Runtime Plan

**Status** — Proposed. Release an explicit checkpoint or range after accepted **M15 U11** renderer refactor and **M16 core (`RT-08D`)**.
**Phase 46** — Asset/evaluator foundation and native rendering (46.1), Studio, gameplay runtime and retargeting (46.2), product acceptance (46.3).
**Architecture** — [Asset, evaluator, Scene, render and Studio contracts](ARCHITECTURE.md).
**Handoffs** — [M20 packaging](../MILESTONE_20_COOKER/PLAN.md), [M21 skeletal LOD](../MILESTONE_21_GEOMETRY_VISIBILITY/PLAN.md), [M22 animation URO](../MILESTONE_22_SIMULATION_SCALE/PLAN.md).

## 1. Product outcome and baseline

A developer can import a skinned FBX or glTF character or standalone motion, edit a clip and controller, assign them in a scene or assembly, preview the result and run the saved character in a detached packaged Runtime. Two actors sharing a rig and compiled controller can have different poses, parameter values, material slot overrides and attachments in the same frame. The visible pose determines depth, shadow, motion and entity picking. The reference character locomotes over a step (with two-bone foot IK and bounded pelvis adjustment) while a masked upper-body reload emits a gameplay event and keeps a prop aligned with the hand socket. The fixture also demonstrates 1D/2D blending, sync markers, additive layers, `AnyState`/grouped transitions and opt-in root motion. A second, differently proportioned rig reuses a source action through a baked target-native clip.

The source baseline includes prototype CPU importers (currently 64-byte vertices without tangents/colors and rejecting meshless files), deep-cloning controller/rig evaluation, transactional document classes, legacy OpenGL skinning coupled into `Axle::Animation`, ECS-bypassing `MeshInstance3D` object picking, auto hex-fallback scene saves and static-only Editor import UI. D3D12 and Vulkan currently reject `Prepared.Skins` as unsupported in `RenderService`. The historical [Phase 40 plan](../../archive/design/deferred/ANIMATION_PHASE_40_COMPLETION_PLAN.md) and [foundation corrections](../../archive/design/reports/ANIMATION_FOUNDATION_FINAL_CORRECTIONS.md) identify relevant existing fixtures and source. M17 is authorized to refactor or replace prototype code across affected modules (`Animation`, `Asset`, `Scene`, `Physics`, `Renderer`, `UI`, `Editor`) rather than preserving broken seams. Reproduce the CPU baseline and record the accepted M15 U11 / M16 renderer topology before assigning current status.

The parent requirements `M17-01` through `M17-08` cover the full product. Each numbered child has one execution owner. M17 proves early and final export through the existing package path (excluding raw FBX/glTF/profile authoring files before M20), enforces `check_architecture.py` compliance, and publishes dependency edges to M20, including the authoring dependencies of a retargeted clip. M21 owns derived geometry LOD and meshlets. M22 owns significance-based pose cadence and bone LOD. The [architecture scope](ARCHITECTURE.md#scope-after-m17) describes later animation extensions.

## 3. Atomic checklist

### M17-01 · Import, codecs and scene binding

- [ ] **M17-01.1 · Reproduce the entry baseline.** Record source/build identity, available authored fixtures, import and extraction callers, native pass/picking seams and supported routes. Run the CPU suite and its failure probe. Record readback metric units and freeze the expected tolerances before candidate scoring.
- [ ] **M17-01.2 · Freeze data and sampling invariants.** Assert parent-before-child ordering, stable joint and structured material slot identities (`SlotID` + default material ref), rig signature, explicit signed bind TRS, inverse-bind composition, 96-byte-compatible `SkeletalVertex` attributes (`Tangent` with handedness `w`, `Color`, unsigned joint indices), `SyncMarkers`/`RootMotionConfig` clip schema and sparse-channel bind fallback. Use an analytic rig for exact key boundaries, held tracks and finite quaternion/cubic results. Reject malformed ranges, identities, influences and incompatible rigs before publication.
- [ ] **M17-01.3 · Wire production imports.** Import procedural, FBX and glTF examples through the project import route. Verify converted/reflected basis, deterministic tangent-frame generation and bitangent handedness `w`, vertex colors, skin and helper ancestry, strongest-four influence normalization and structured material slots. Cover glTF STEP/LINEAR/CUBICSPLINE and FBX STEP/STEP-next and sampled bake. Report malformed or unsupported skin selections.
- [ ] **M17-01.4 · Publish complete generations and reimport.** Save and read back native mesh, v3 binary skeletal geometry (`SkeletalGeometryCodec` v3), rig and clip generations (with AF-01 `# AxleFileIdentity: 1` identities, `Events`, `SyncMarkers`, `RootMotionConfig`) and verify references and numeric round trips. Extend `AssetManager` move/rename rewriting to cover `AssetDSL` `*Ref` properties. Confirm unchanged reimport and supported rename/reorder retain identities. Reject ambiguous remaps. Verify discovery and export select the same committed generation. Exercise truncated binary, missing external glTF buffer, collapsed source times, stale jobs and simulated write failure. Confirm the prior generation remains usable.
- [ ] **M17-01.5 · Share binding across real callers.** Use the same mesh/controller and per-slot material/parameter overrides in Scene, direct assembly instantiation and assembly editor. Make inline fallback (`RigFallbackData`, `InlineFallbackData`) strictly opt-in in `SceneSerializer`/`AssemblySerializer` rather than automatic. Test shared and detached assets, an explicitly saved inline fallback, a valid mesh with bad controller and a missing required mesh without fallback (asserting explicit failure). Verify diagnostic context includes the owning reference.
- [ ] **M17-01.6 · Isolate instances and enumerate dependencies.** Duplicate an actor and create an Edit-to-Play copy. Verify independent active states, clocks and triggers, explicit reset on stop/rebind, and shared immutable clip/skeleton pointers across instances (no deep copy per clone). Enumerate typed owner-to-target edges for geometry, rig, clips/controller and slot materials. Resolve an authored binding using its native geometry with raw FBX/glTF unavailable.
- [ ] **M17-01.7 · Establish the CPU module and Scene publication boundary.** Build and run the evaluation path without Renderer, RHI, Scene, physics or Editor dependencies by severing `Axle::Renderer` from `Engine/Animation/CMakeLists.txt`, removing `VertexArray` from `SkeletalMesh` and `SkinningPipeline`/`Shader` from `Animator`, updating `scripts/architecture_rules.json` (`check_architecture.py` exit 0), and verifying a pure `Axle::Animation`-only CPU test link target without `Axle::Scene`. Move OpenGL geometry ownership to the render boundary and keep the existing compatibility route. Observe one committed pose per executed tick, two isolated actors, stale job result rejection and a binding swap that retains the last ready pose and resources until the new generation commits.
- [ ] **M17-01.8 · Import and reimport motion independently.** Import meshless/animation-only FBX and glTF through `SkeletalMeshImporter` (lifting `meshes.empty()` rejection for valid hierarchies) and the Editor by choosing a take and compatible rig without creating a mesh. When no compatible rig exists and the source supplies a complete valid reference hierarchy and bind data, publish a validated source `Skeleton` rig alongside the clip for retargeting. Diagnose missing or ambiguous joint mapping or incomplete reference transforms. Save and reopen a native clip, resample it in the shared evaluator and verify stable identity and rollback on failed reimport.

### M17-02 · Native skinning and pass integration

- [ ] **M17-02.1 · Validate the native mesh.** Convert v3 CPU geometry into 96-byte `RHISkinnedVertex3D` buffers (`RHISkinnedMesh` / parameterized `RHIMesh` with indexed submeshes carrying `MaterialSlot`). - [ ] **M17-02.2 · Validate the extracted packet and bounds.** Refactor `RenderSkinInstance` off `GLMesh` to carry immutable entity/instance identity, native mesh/rig/pose generations, current/previous transforms, slot material bindings, caster flags and conservative deformed bounds computed from posed joint influence boxes. - [ ] **M17-02.4 · Prove native deformation.** Compare CPU vertices and tangent frames with native captured results for bind pose, translation, rotation and signed/nonuniform scale.
