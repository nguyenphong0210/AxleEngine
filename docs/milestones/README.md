# AxleEngine Milestones Directory

Each active Milestone (Milestones 12 through 18) owns exactly two canonical documents:
- `PLAN.md`: Granular work breakdown, status checkboxes, child Phases, and review criteria.
- `ARCHITECTURE.md`: Subsystem architectures, Mermaid diagrams, data contracts, and technology limits.

The root [ROADMAP.md](../../ROADMAP.md) is the single source of authority for execution order.
