# AxleEngine Milestones Directory

This directory organizes all milestone-level plans and technical architecture documents:

- **Historical Foundations (Milestones 01 to 11)**:
  - Each milestone directory owns a canonical `PLAN.md` documenting historical requirements, breakdown of child phases (Phases 1 through 41), and completed verification checklists.
- **Modern Technical Milestones (Milestones 12 to 18)**:
  - Each active milestone directory owns companion documents:
    - `PLAN.md`: Granular work breakdown, status checkboxes, child phases (Phases 42 through 48), and review criteria.
    - `ARCHITECTURE.md`: Subsystem architectures, Mermaid diagrams, data contracts, and technology limits.

The root [ROADMAP.md](../../ROADMAP.md) is the master index and source of authority for milestone execution order.
