# Phase documents

Each Phase has exactly two active documents:

- `PLAN.md` — ordered work, checkboxes, dependencies, commits, tests, review and acceptance.
- `ARCHITECTURE.md` — target architecture, module boundaries, algorithms, technology choices, fallback and limits.

The root [ROADMAP.md](../../ROADMAP.md) is the only execution order. OPT/C-package
labels inside these documents identify historical scope and evidence; they do
not form another roadmap.
