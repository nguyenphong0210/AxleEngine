# Milestone Documents

Each Milestone has exactly two active documents under `docs/phases/`:

- `PLAN.md` — ordered work, checkboxes, dependencies, commits, tests, review and acceptance.
- `ARCHITECTURE.md` — target architecture, module boundaries, algorithms, technology choices, fallback and limits.

The root [ROADMAP.md](../../ROADMAP.md) is the only execution order. OPT and Phase are unified: each Milestone manages its sequential child Phases.
