# M14-U4 — Phase 44.7 GTAO

## Status

Implemented and verified. Scene rendering now has an explicit depth-backed GTAO stage between scene composition and tone mapping/FXAA. It copies the resolved scene color and depth into owned auxiliary targets, evaluates an eight-direction half-resolution footprint, and applies depth-aware occlusion before the remaining post-processing stages. The feature is opt-in through `SceneRenderSettings::EnableGTAO` and degrades cleanly when depth or auxiliary targets are unavailable.
